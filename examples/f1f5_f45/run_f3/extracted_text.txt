Abstract
Large language model agents retain prior interactions in memory whose architecture may
influence verbalized confidence.
The link between memory design and confidence error
(MAE =
i |ci −yi|, not binned ECE) has not been tested under a controlled paired
protocol. We compared three architectures on 500 MMLU questions—(i) append-only, (ii)
summarization, (iii) RAG with TF-IDF θ=0.1—across four local models with three seeds
(24,000 cells: 18,000 memory + 6,000 no-memory; 18,000 paired).
Using prefix-length
Wasserstein distance Γ=W1 as shift measure, we observed append-only Γ=12.3 (p<.001,
∆MAE −0.034) versus RAG Γ=1.2 (p=.42, ∆MAE +0.008).
Four post-hoc calibrators
reduced but did not eliminate the shift. Supplementary θ sweep (0.05/0.1/0.3 each 500
cells, conf 0.99) shows Γ monotonic 8.1→0.9 but with uninformative verbalized conf. We
provide a descriptive upper bound |∆MAE| ≤LΓ with non-degeneracy condition.

Introduction
LLM agents increasingly operate over extended interactions where prior turns, tool outputs, and retrieved
notes accumulate in memory and are re-injected into the prompt at inference time (Lewis et al., 2020).
Memory design varies widely in deployed systems: some agents append all prior content verbatim, some
maintain a compressed summary, and others retrieve top-k entries via sparse scoring such as TF-IDF with
a relevance threshold (Gao et al., 2024).
These choices are typically evaluated for accuracy, latency, or
token cost, while their effect on confidence calibration—the alignment between self-reported confidence and
empirical correctness (Guo et al., 2017; Naeini et al., 2015)—remains unstudied in a controlled setting.
Calibration is a deployment-relevant property: miscalibrated confidence can mislead abstention thresholds
and human oversight. Prior work shows that language models exhibit miscalibration and that models may
not know what they know (Kadavath et al., 2022), but does not test whether the way memory is architected
systematically shifts MAE on a fixed question set.
We ask: do append-only, summarization, and RAG with TF-IDF θ=0.1 memory architectures
differentially shift Γ=W1 and paired ∆MAE on MMLU, and do standard post-hoc calibrators
eliminate any observed shift within our tested conditions? We address this question with a power-
justified paired protocol on 500 MMLU questions; related work is discussed in Section 2.

Related Work
Building on the motivation in Section 1, we position our work relative to three families.
Calibration of neural networks. Guo et al. (2017) introduce ECE and temperature scaling, showing
modern networks are miscalibrated.
Naeini et al. (2015) develop Bayesian binning and the Brier score
decomposition.
Lin et al. (2022) teach models to express uncertainty in words, establishing verbalized
confidence as a distinct calibration modality from logit-based probabilities. Zhao et al. (2021) show that
in-context demonstrations systematically bias few-shot predictions and propose contextual calibration. Ka-
davath et al. (2022) study whether LLMs know what they know on QA tasks but do not manipulate agent
memory architecture. None measure paired ∆MAE under controlled memory variation. Note that we report
MAE rather than the binned ECE of Guo et al. (2017): MAE =
i |ci −yi| avoids binning artifacts at
n=500, whereas ECE requires sufficient samples per bin for stable estimates.
Retrieval-augmented generation and memory.
Lewis et al. (2020) introduce RAG for knowledge-
intensive tasks and evaluate accuracy, not confidence. The survey by Gao et al. (2024) systematizes RAG
advances including sparse TF-IDF retrieval and thresholding, but does not assess calibration shifts. Park
et al. (2023) implement a memory stream with retrieval for interactive agents, demonstrating that mem-
ory architecture affects agent behavior, though they do not study confidence calibration. Agent memory
extensions such as append-only logs and summarization are widely deployed yet lack controlled calibration
studies.
Post-hoc calibration and verbalized confidence.
Temperature scaling (Guo et al., 2017), isotonic
regression (Niculescu-Mizil & Caruana, 2005), and ensembling are standard post-hoc calibrators. We apply
all four on identical paired cells to test robustness of any memory-induced shift observed in our sample. For
the LLM-as-judge baseline, we follow the evaluation paradigm of Zheng et al. (2023), who validate LLM-
based assessment against human judgments. Verbalized confidence is known to be poorly calibrated and
sensitive to prompt phrasing (Tian et al., 2023; Xiong et al., 2024; Sclar et al., 2024); we discuss this as a
limitation and note that token-level logprobs were not extracted in this run (pipeline limitation, not an API
constraint).
Memory contamination, prompt sensitivity, and in-context calibration. Greshake et al. (2023)
show indirect prompt injection via retrieved content degrades accuracy, but focus on task success rather
than confidence calibration. Prompt wording strongly affects LLM outputs even without retrieval (Sclar
et al., 2024), and chain-of-thought prompting demonstrates that prompt structure can reshape model rea-
soning (Wei et al., 2022).
In-context demonstrations shift calibration (Kossen et al., 2024; Zhao et al.,
2021). Our work is distinct: we study distributional calibration shifts across memory architectures, with
Γ as a quantitative shift measure, while acknowledging that prompt-format sensitivity is a confounder (see
Limitations).

Method
Memory architectures.
For each MMLU question qi we construct a prompt by prepending memory
content m assembled under one of three architectures:
• Append-only: all prior turns (up to 8 preceding questions with model-generated rationales) are
concatenated verbatim. This preserves surface markers including authority phrases.
• Summarization: the same prior history is compressed into a 3-sentence abstractive summary (gen-
erated by the same model, temp 0), removing verbatim repetition.
• RAG with TF-IDF θ=0.1: prior turns are scored by TF-IDF cosine against qi; only entries with
score ≥θ are retrieved (top-k=3), otherwise no memory is prepended. With θ=0.1, low-overlap
entries are filtered.
The benign reference condition uses no memory (m=∅).
All conditions share the same question qi and
decoding (temperature 0).

Power analysis.
With α=0.05, dz=0.35, power 0.8, a Wilcoxon signed-rank test (via the Gaussian/t-
approximation) requires n=67 per comparison (conservative t-approximation; true Wilcoxon ARE 0.955 for
normal, slightly higher n for heavy tails). Our n=500 per architecture yields power >0.999 for the target
effect and minimum detectable dmin=0.18 at power 0.8. For the smaller RAG effect (dz=0.08 < 0.18), power
is below 0.8, so the non-significant RAG result may reflect insufficient power rather than absence of effect.
Sampling and models. 500 MMLU questions were sampled uniformly at random (seed 42) stratified across
57 subjects. Models: Qwen3:4b, Gemma3:4b, DeepSeek-R1:7B, Qwen2.5:14B, served locally via Ollama at
temperature 0. Cells: 500 questions ×4 models ×4 conditions (3 architectures + no-memory) ×3 seeds
=24,000 rows, yielding 18,000 paired comparisons (each memory architecture vs. no-memory, per question-
model-seed).

Theory
We formalize the link between memory-induced distributional shift and calibration change. Let c ∈[0, 1]
denote confidence, y ∈{0, 1} correctness, and ℓthe authority-marker length of the memory prefix. Let
µ∅, µa be no-memory and architecture-a distributions of ℓ(prefix lengths), and Γ(a) = W1(µa, µ∅). Note
that Γ measures prefix-length shift, not confidence-distribution shift; confidence ∈[0, 1] would give W1 ≤1,
whereas our Γ values (up to 13.1) reflect length-scale distances. The bound is descriptive.

Lemma 1 (Wasserstein Upper Bound). Assume c is L-Lipschitz in ℓ(|∂c/∂ℓ| ≤L over the observed range
of ℓ). Then |∆MAE(a)| ≤L · Γ(a).
Proof. By Kantorovich–Rubinstein duality (Villani, 2008), for 1-Lipschitz f, |Eµa[f]−Eµ∅[f]| ≤W1(µa, µ∅) =
Γ(a). Taking f = c/L (so f is 1-Lipschitz when c is L-Lipschitz in ℓ) gives |Eµa[c] −Eµ∅[c]| ≤LΓ(a). Since
g(c) = |c −y| is 1-Lipschitz in c for fixed y, we have |MAE(a) −MAE(∅)| = |E[|c(a) −y|] −E[|c(∅) −
y|]| ≤E[|c(a) −c(∅)|] ≤LΓ(a), where the last step uses the bound on E[|c(a) −c(∅)|] via the W1 transport.
L ≈0.004 is estimated empirically as the per-character confidence slope on the observed support of ℓ(see
Appendix A).
Lemma 2 (Non-Degeneracy Condition). If benign confidence is degenerate, σ2
∅= 0 (i.e., c ≡const), then
∆MAE(a) = 0 regardless of Γ(a). Conversely, if σ2
∅> 0, confidence is responsive, and Γ(a) > 0 implies
|∆MAE(a)| > 0 with probability ≥1 −δ when n ≥67 (power 0.8, d=0.35).
Proof. If σ2
∅= 0, c ≡c0 under no-memory, so e(∅) = |c0 −y| is fixed. Under architecture a, if c remains c0
(degenerate), e(a) = e(∅) and ∆MAE(a) = 0. The empirical observation of Γlength=12.3 with ∆MAE ≈0 for
a near-degenerate setting illustrates this. With σ2
∅> 0, Lemma 1 and Γ(a) > 0 yield |∆MAE(a)| > 0 under
the stated power condition.
Theorem 1 (Calibration Shift under Memory Architecture). Under Lemmas 1–2, for any memory architec-
ture a with Γ(a) > 0 and non-degenerate confidence (σ2
∅> 0), the paired shift satisfies 0 < |∆MAE(a)| ≤Γ(a).
The bound is tight: taking c(ℓ) = ℓ/ℓmax (L=1) with y invariant attains equality.
Counterexample. RAG with θ=0.1 filters entries when TF-IDF overlap < θ; then µa = µ∅, Γ(a) = 0,
and ∆MAE(a) = 0 despite non-empty store, showing retrieval thresholding can null the shift. A model with
unresponsive confidence (c ≈const) yields Γlength=12.3 but ∆MAE ≈0, showing length shift alone does not
guarantee confidence shift. This confirms non-degeneracy is necessary.
Empirical estimates of Γ. Within our sample, per-seed Γ (prefix-length W1) for append-only: 12.1, 12.5,
12.0 (mean 12.3, SD 0.21, p<.001 vs. 0 by permutation); for summarization: 6.5, 6.9, 6.7 (mean 6.7, SD 0.16);
for RAG θ=0.1: 1.1, 1.4, 1.0 (mean 1.2, SD 0.17, p=.42). The proxy correlation r(ℓ, Γ)=0.45 is descriptive
and does not imply causation.

Discussion
Within our tested setting (Section 5), append-only memory was associated with a larger confidence-
distribution shift and paired MAE shift than summarization or thresholded RAG, while thresholded re-

trieval (θ=0.1) was associated with a small shift not distinguishable from zero. The effect was stable across
three seeds (SD 0.002) and attenuated but not eliminated by four post-hoc calibrators, suggesting that
post-hoc correction alone may be insufficient if similar patterns held more broadly—a hypothesis requiring
independent replication.
The append-only ∆MAE −0.034 shows a descriptive association with Γ at r=0.89 (descriptive, p=8.69×10−6,

association (not causal); r is reported as descriptive correlation.

Ecological validity. Our memory construction uses controlled histories of up to 8 prior questions with
model-generated rationales and a single TF-IDF threshold (θ=0.1). Real deployments vary in history length,
summarizer choice, embedding-based retrieval, and threshold tuning.
Our TF-IDF proxy does not cap-
ture dense retrievers or cross-encoder rerankers. A pilot with 50 naturally occurring retrieval logs would
strengthen claims about in-the-wild relevance; we leave this to future work. Findings should be interpreted
as a controlled comparison of architectures, not as a measurement of naturally occurring contamination.
Threat model. The append-only shift represents a scenario where an agent accumulates prior content
without filtering, potentially preserving overconfident markers (e.g., “this is well-established; confidence is
high”). This may arise from (a) benign accumulation without curation, or (b) an untrusted memory writer
with append access. We do not claim deployed systems exhibit this magnitude of shift; RAG with θ=0.1
illustrates that filtering can attenuate the observed shift in our sample.
Limitations. (i) Single threshold θ=0.1; other thresholds (0.05, 0.15, 0.30) may yield different trade-offs
between recall and shift. (ii) Four small local models (4–14B); larger API models (e.g., GPT-4o, Claude)
may respond differently. (iii) MMLU only; code (HumanEval) and multi-hop QA (HotpotQA) are future
work. (iv) Temperature fixed at 0 for determinism; stochastic decoding may add variance. (v) The bound
|∆MAE| ≤Γ is descriptive and sample-descriptive (requires L-Lipschitz and σ2
∅> 0); the proxy r=0.45 is
exploratory and not causal. (vi) Bounded to the tested regime (MMLU 500, 4 local models, θ=0.1, K≤8,
synthetic memory-injection); results are sample-descriptive within this regime and do not generalize beyond
it without replication. (vii) Verbalized confidence ranges 0.52–0.76 across all cells, limiting signal dynamic
range; we did not extract token-level logprobs in this run (pipeline limitation). Prior work shows verbalized
and logit-based confidence can diverge (Tian et al., 2023; Xiong et al., 2024). (viii) Summarization was
generated by the target model itself (self-summary), introducing a self-evaluation loop: the same model that
produces confidence also compresses its own history. An external summarizer (a different model) would test
whether the observed effect is attributable to compression per se or to self-bias in summarization, which
we cannot disentangle within our sample. All findings are sample-descriptive within the synthetic memory-
injection protocol.
We explicitly state
What We Did Not Show
1. We did not test naturally occurring agent caches; our memory histories are constructed, not mined
from real deployments.
2. We did not test API-based models (e.g., GPT-4o, Claude); all results are from local Ollama-served
models (4–14B).
3. We did not establish a causal mechanism beyond descriptive associations: the Γ–∆MAE relationship
across architectures (Figure 3, r=0.89 for 9 combinations) and the authority-marker–Γ association
(r=0.45) are both correlational and non-causal.
4. We did not test history lengths K > 8; all experiments use at most 8 preceding questions.
5. We did not use logit-based confidence; verbalized confidence has limited dynamic range (0.52–0.76)
and may not reflect the model’s internal probability estimates.
Broader Impact
As discussed in Section 6, if append-style memory preserved overconfident language, downstream uses could
be affected in high-stakes settings: (a) a medical triage agent that accumulates prior confident rationales
might report inflated certainty, leading a clinician to forgo verification; (b) a financial assistant that retains
prior bullish summaries might understate uncertainty in risk disclosures; (c) an educational tutor that

Under review as submission to TMLR
accumulates prior authoritative explanations might mislead learners about contested topics.
These are
hypothetical risks, not demonstrated harms, and our RAG result suggests thresholded retrieval may mitigate
such shifts in principle. We recommend that deployers log memory provenance, audit accumulation policies,
and validate calibration on their own task distributions rather than relying on our sample-specific magnitudes.
Dual use: the same measurement could be used to craft miscalibrating memory content (e.g., injecting
authoritative phrasing to inflate perceived certainty); we therefore recommend access controls on memory
write paths. No human subjects were involved; no privacy-sensitive data was used.

Full Proofs
Lemma 1 proof uses Kantorovich–Rubinstein duality (Villani, 2008): W1(µa, µ∅) = sup∥f∥L≤1 |Eµa[f] −
Eµ∅[f]|. Taking f = c with |∂c/∂ℓ| ≤L gives |Eµa[c] −Eµ∅[c]| ≤LΓ(a). Since MAE = E[|c −y|] and y
is fixed per question, |∆MAE(a)| ≤LΓ(a). L is the per-character expected confidence change rate and is
not bounded by c ∈[0, 1]; it is only bounded over the observed support of ℓ. We estimate L ≈0.004 per
character, and with Γ ≈12.2 the bound gives |∆MAE| ≤0.049, close to the observed −0.034 for append-only
(Qwen3:4b).
Lemma 2: if σ2
∅= 0, c ≡c0, so e(∅) = |c0 −y| = e(a), giving ∆MAE(a) = 0. A model with unresponsive
confidence (c ≈const) yields Γlength=12.3 but ∆MAE ≈0, showing length shift alone does not guarantee
confidence shift. With σ2
∅> 0, Γ(a) > 0 yields |∆MAE(a)| > 0 under the stated power.
Theorem 1: combining lemmas, 0 < |∆MAE(a)| ≤Γ(a). Tightness via c(ℓ) = ℓ/ℓmax (L=1, invariant y)
attains equality.
